# Materials Event Modeling

Use this memo to resume the repository or judge a proposed experiment. Historical results and run
chronology live in their result documents, not here.

## Working claim

Labels, reports, and features are candidate task-specific compressions. For a declared downstream
decision, measure where the experimental record first loses usable information, support, or
distinguishability; test whether any richer signal transfers across environments; and record whether
upstream evidence remains recoverable.

Neither raw traces nor labels are privileged in advance. A compact report is preferred when it
meets frozen risk, support, transfer, latency, and cost bounds. `Raw` always means relative to a
declared pipeline edge.

## Current scope

The active program is a prospective partner study with this chain:

```text
measurement opportunity
-> instrument-native artifact
-> adapter / transformation DAG
-> actual conventional report
-> delayed outcome
-> early action
```

The next evidence-producing gate is one real, nonconfirmatory golden bundle. Do not expand the
schema, start a model sweep, or claim downstream value until native evidence, capture omissions,
lineage, report construction, clocks, units, censors, outcomes, and costs reconcile.

The CaCO3 study remains a methods calibration. A degradation, qualification, scale-up, or functional
endpoint requires a separate preregistration and the correct descendant-unit graph.

## Non-negotiable design rules

1. **Declare the audit root.** Inventory measurement opportunities, native artifacts, and adapter
   omissions. A signal dropped before every arm is invisible to the audit.
2. **Price compression before outcomes.** For every omitted channel or record, state the result it
   could preordain and the experiment that would test it.
3. **Use the actual report.** A feature packet invented after outcome access is not a conventional
   comparator.
4. **Keep denominators separate.** Attempt, target eligibility, follow-up, assay, representation
   availability, censoring, and failure are different states.
5. **Respect physical independence.** Cycles, spectra, aliquots, specimens, and devices do not
   become independent material batches by occupying separate rows.
6. **Stress provenance.** Report random/grouped performance only beside held-batch, held-session,
   or held-site results appropriate to the claim.
7. **Beat cheap explanations.** Include recipe/context, mean, clock, interpolation, event identity,
   and provenance-only baselines when applicable.
8. **Freeze before running.** Commit the task, expected result, reversal condition, split, learner
   family, uncertainty rule, and decision changed by the result.
9. **Preserve nulls and failures.** A null earns bounded adequacy only for the tested task, data,
   learner family, environments, and tolerance.
10. **Prefer lineage over prose.** Use hashes, versions, reader recipes, and machine-resolvable
    parentage. Disclosure without an executable consequence is not control.

## Claim boundaries

Established calibration lessons:

- public experimental records can encode collection provenance;
- inherited categories can be adequate, redundant, or locally lossy;
- paper-shaped projections can delete event and decision support by construction;
- dense trajectories can add no usable value beyond time/interpolation; and
- within-corpus signal need not survive a held collection environment.

Not established:

- that raw traces generally outperform labels;
- that an embedding recovered a true or natural materials ontology;
- that current public-data effect sizes represent industrial laboratories;
- that the Severson adapted record included its strongest native signal; or
- that this program predicts reproducibility, degradation, yield, qualification, or functional
  performance before a prospective partner study passes.

## Stop rules

- No new public-dataset, synthetic-policy, JEPA, or architecture sweep unless it closes a named
  prospective design uncertainty.
- No scientific claim from the synthetic golden bundle.
- No causal language from predictive importance alone.
- No reproducibility claim without independent sites; within-lab changes test intermediate
  precision.
- No deletion recommendation merely because a compressed arm is adequate for one task. Future
  tasks and incident review can justify retaining immutable upstream evidence.
